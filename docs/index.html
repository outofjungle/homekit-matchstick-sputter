Matchstick 0x02 Pairing QR Code Decoder

Click each LED image to match what you see on the device, then scan the QR code below.

How to trigger the LED display:

  1. Press and hold the reset button on the Matchstick board
  2. After 3 seconds, the LEDs will reset to their default colors — keep holding
  3. After 10 seconds, the LEDs will turn solid purple — keep holding
  4. After 15 seconds, the LEDs will display the pairing config ID as a binary color pattern (blue and red LEDs) for about 10 seconds — this is the pattern you need to read
  5. Release the button now — if you keep holding past the 10-second display, the device will factory reset and erase all settings, including WiFi configuration
  6. Read the LEDs: Look at the LED strip from the connector end (see board image). LED 1 (LSB) is closest to the board connector. Read all 8 LEDs and tap the matching color below for each LED position.

Once all 8 LED colors are set, the decoder will look up the matching release tag. If the pattern corresponds to a valid build, the pairing QR code will be displayed below. If not, you will see an error indicating the release was not found.

Blue = 0 Red = 1 White = not set
